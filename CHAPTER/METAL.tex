\chapter{Metal}
This chapter introduces several frameworks for developing metal models.
The basic one is the von Mises framework, which is also called the J2 model in some literature as it adopts the second invariant of the deviatoric stress to characterise the yield function.
The intermediate model is the VAFCRP model, which implements a Voce-type nonlinear isotropic hardening, a multiplicative Armstrong--Frederick-type kinematic hardening and a Peric-type viscosity.
Thus, this model can account for dynamic effects.
The third is a general framework built on the Hoffman criterion, suitable for orthotropic materials.
